# focoach downloads

Public desktop app installers for [focoach](https://focoach.com). This repository contains download instructions and release assets only.

## Version 0.4.4

- [Mac Universal ZIP](https://github.com/penguiin1/focoach-downloads/releases/download/v0.4.4/focoach-mac-universal-0.4.4.zip) — Apple Silicon and Intel, macOS 14 or later.
- [Windows x64 installer](https://github.com/penguiin1/focoach-downloads/releases/download/v0.4.4/focoach-windows-x64-0.4.4-setup.exe).
- [SHA-256 checksums](https://github.com/penguiin1/focoach-downloads/releases/download/v0.4.4/SHA256SUMS.txt).

On Mac, extract the ZIP and move `focoach.app` to Applications. This Mac build has not been notarized by Apple.

On Windows, run the EXE and follow the installation wizard. The installer is not code signed. It includes the official Microsoft Visual C++ x64 runtime and installs it when needed.

For current downloads, installation instructions, and support, visit [focoach.com/download](https://focoach.com/download).
